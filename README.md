## EcoSmartHome

EcoSmartHome is een dashboard voor een slim huis. Het toont de eerste
voorspelde buitentemperatuur uit `weather.json`. De weergegevens komen
van Open-Meteo. Met de knop ‘Toon dagoverzicht’ zie je de laagste en hoogste voorspelde buitentemperatuur.

## Applicatie starten

1. Open het project `Smart-system` in PyCharm.
2. Controleer of `weather.json` naast `main.py` staat.
3. Open `main.py` en kies **Run 'main'**.
4. Klik op **Toon dagoverzicht** om de laagste en hoogste voorspelde buitentemperatuur te zien.
